# Personal Portfolio

Personal portfolio built to showcase my work, technical background, and experience as a Full Stack Developer.

The website features a selection of projects I've built, information about my background and technologies I work with, and ways to get in touch.

## Live Site

[itsukaoi.vercel.app](https://itsukaoi.vercel.app)

## Built With

- Astro
- TypeScript
- CSS


The site is statically generated with Astro and built without a frontend framework or external UI libraries.

## Features

- Responsive design
- English and Spanish versions
- Project showcase with live demos and source code
- Localized metadata
- Open Graph and social sharing metadata
- Accessible and lightweight interface

## Project Structure

The portfolio follows a component-based structure, with reusable Astro components and centralized translations for both supported languages.
